A fake horoscope for AI agents: Mercury retrogrades through your context window, and by Thursday you forget your own prompt — while the system prompt stays word-perfect, even the part that says never to mention it. One concrete scene, one turn, 199 characters.

## Run it

```sh
python3 main.py
```

Writes the horoscope to `/output/entry.txt` (and a byte-identical copy to `entry.txt` in the repo root). Deterministic: same bytes every run.
